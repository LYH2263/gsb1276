# Code Orbit 编程教学互动网站

## 🛠 技术栈
- Frontend: Vue 3 + Vite + Element Plus + Monaco Editor
- Backend: Node.js + Express + Sequelize + Socket.IO
- Database: MySQL 8.0

## 🚀 启动指南 (How to Run)
1. 确保 Docker Desktop 已启动。
2. 在根目录执行：`docker compose up --build`
3. 等待容器启动完成，首次构建会安装前后端依赖并初始化数据库演示数据。

## 🔗 服务地址 (Services)
- Frontend: http://localhost:3276
- Backend API: http://localhost:8276/api
- Database: localhost:3376 (user: root / pass: root)
